Address review feedback systematically.

## Process

### 1. Classify feedback
- **Must fix**: bugs, security, logic errors
- **Recommended**: readability, naming, structure
- **Needs discussion**: design direction, trade-offs

### 2. Order of work
1. Must-fix items first
2. One commit per piece of feedback so the reviewer can verify each
3. Items needing discussion: reply with your view and change only after agreement

### 3. Replying
- Reply to every comment ("Fixed", or your reasoning if you disagree)
- Do not get defensive
- Try to understand what the reviewer intends
- When you disagree, explain politely with evidence

### 4. Re-request
- Request re-review after all feedback is addressed
- Leave a comment summarizing the changes
