Summarize the changes on the current branch.

1. Check `git log` and `git diff`
2. Summarize as:
   - **Work done**: 1 to 3 lines
   - **Changed files**: the main ones
   - **Remaining**: anything still to do

Write it so it can go straight into a PR description or a daily standup.
